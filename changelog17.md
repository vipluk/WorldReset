# Changelog - WorldReset v1.7

### 🚀 Official Release & Changes
* 🌟 **Stable Release (Out of Beta):** WorldReset 1.7 is now officially out of beta! Since no issues or bugs were reported during the testing period, version 1.7 is promoted to a fully stable production release.
* 📈 **FastStats Integration:** Integrated anonymous server metric tracking via [FastStats.dev](https://faststats.dev) to help monitor plugin adoption, performance, and Minecraft version usage without any performance impact.
